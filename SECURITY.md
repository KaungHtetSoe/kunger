# Security Policy

Kunger is a read-only system-inspection tool. It never requires root, never invokes `sudo`, and
never executes discovered software. See [`docs/SECURITY.md`](docs/SECURITY.md) for the full
security model, scope boundaries, and threat considerations, and
[`docs/SECURITY_REVIEW.md`](docs/SECURITY_REVIEW.md) (once published) for the results of the
pre-release security review.

## Reporting a vulnerability

This project does not yet have a public release or a dedicated security contact channel. Until
one is established, please open a GitHub issue with as much detail as you can share publicly, or
mark it clearly as security-sensitive if the repository's issue tracker supports private
reporting, and avoid including exploit details that could be used against real systems before a
fix is available.

## Supported versions

Kunger has not yet reached a 0.1.0 release. There are no supported versions yet.
